# Security Policy

## Reporting a vulnerability

Please do not open public issues for suspected vulnerabilities.

Until official reporting channels are configured for `pinterest/alloy-graphql`,
please report vulnerabilities privately to the maintainers through internal
Pinterest security reporting channels.

If you are an external reporter and do not have access to internal channels,
open a GitHub issue with minimal details and request a private follow-up channel
from maintainers.

## Response expectations

Maintainers will:

- Acknowledge receipt as quickly as possible.
- Investigate and triage impact.
- Coordinate disclosure and remediation timing.

## Scope

This policy applies to source code and published package artifacts for this
repository.
