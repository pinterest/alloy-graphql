# Support

## Getting help

- For usage questions and general discussion, open a GitHub issue in this
  repository.
- For bug reports, include a minimal reproduction and environment details
  (Node version, pnpm version, package version).

## Before opening an issue

- Check existing issues to avoid duplicates.
- Confirm the issue reproduces on the latest local code (`pnpm test`, `pnpm build`).
- Include relevant schema snippets and expected vs actual behavior.

## Security issues

For security concerns, follow `SECURITY.md` instead of posting public details.
